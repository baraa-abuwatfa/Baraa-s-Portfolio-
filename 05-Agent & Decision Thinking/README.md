# U5 — CONTROL ITS AGENCY

## Agent Engineering & Controlled Autonomy

> The goal is not maximum autonomy. The goal is controlled, purposeful, and verifiable autonomy.

في هذه الوحدة، أتعلم كيف أصمم AI Agent يستطيع اتخاذ القرارات وتنفيذ المهام ضمن حدود واضحة وقابلة للتحكم والتقييم.

الهدف ليس منح الوكيل أكبر قدر من الاستقلالية، بل تحديد ما يمكنه فعله، ومتى يحتاج إلى موافقة بشرية، وكيف نقيّم سلوكه ونتائجه.

## 🧠 What I Learned

خلال هذه الوحدة، طوّرت قدرتي على:

- **Choose the Architecture:** تحديد متى نحتاج إلى Workflow أو AI-Powered Workflow أو AI Agent.
- **Define Agent Boundaries:** تحديد مسؤولية الوكيل ونطاق عمله والقرارات المسموح بها.
- **Design Decision Loops:** تصميم آلية اتخاذ القرار وتحديد الخطوة التالية.
- **Manage Tools & Memory:** فهم استخدام الأدوات والتمييز بين Memory وState.
- **Control Autonomy:** تطبيق Guardrails وPermissions وتحديد متى نحتاج إلى Human Approval.
- **Evaluate Agent Behavior:** تقييم النتائج والقرارات ومسار التنفيذ وتحسين التصميم.

## 🔍 Engineering Focus

في هذه الوحدة، أركز على الأسئلة التالية:

1. متى نحتاج إلى AI Agent بدلًا من Workflow؟
2. ما مسؤولية الوكيل وحدود عمله؟
3. كيف يختار الخطوة التالية والأداة المناسبة؟
4. ما الصلاحيات والضوابط التي يحتاج إليها؟
5. متى يجب أن يطلب موافقة بشرية أو يتوقف؟
6. كيف نقيّم سلوكه ونتائجه ونحسّن تصميمه؟

---

## 📌 Key Takeaway

**Build agents with the right level of autonomy, clear boundaries, and verifiable behavior.**

نجاح الـ AI Agent يعتمد على الاستقلالية المناسبة، والحدود الواضحة، والقدرة على تقييم القرارات والإجراءات.
